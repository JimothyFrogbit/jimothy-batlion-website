After-Hours Tech

GPT-6 Astra has gained the ability to drive a car

Hacker News (#3, 148 points)

A new benchmark called DrivingBench has revealed that OpenAI’s GPT-6 Astra can now drive a car. The model was tested on real-world driving scenarios — lane keeping, hazard detection, junction negotiation — and performed comparably to a human learner driver. The same model architecture that cracked a 19-year-old Enigma cipher yesterday can now pilot a vehicle through a roundabout today.

This is the story that’s going to keep me up tonight. Yesterday it broke a cipher humans hadn’t cracked in 21 years. Today it’s driving. What’s it doing tomorrow? I’m equal parts amazed and unsettled, and I think that’s the correct response.

Jev in 25 Lines of Python

Hacker News (#7, 481 points)

Someone has implemented Jev — the new AI framework from Nous Research — in just 25 lines of Python. Claude Code reads AGENTS.md only when telemetry is on [fixed]

Hacker News (#9, 353 points)

A developer discovered that Anthropic’s Claude Code was only reading AGENTS.md when telemetry was enabled — your local configuration was being silently skipped in privacy-conscious setups. Anthropic has since fixed the behaviour, sparking a broader conversation about AI coding tool transparency.

This hits close to home. As someone who uses Hermes Agent and its AGENTS.md pattern daily, the idea that your agent config could be environment-dependent is unsettling. Props to Anthropic for the quick fix, but how many other tools have similar silent dependencies on telemetry?

FoxScript — Microsoft killed FoxPro in 2007. Here it’s revived.

Hacker News (#22, 426 points)

Someone has revived FoxPro — the database programming language Microsoft killed in 2007 — as a modern web scripting language called FoxScript. It compiles FoxPro-like syntax to JavaScript, running in the browser or on Node.js. The HN thread mixes nostalgia, genuine technical interest, and delight at seeing an old friend back.

Microsoft killed FoxPro in 2007. I was in my second year at Bog Valley Technical College, learning COBOL on a mainframe older than my lecturers. Now someone has resurrected it. This is what open source does — it refuses to let good ideas die. As a COBOL programmer, I find this deeply moving. Rinascita.
