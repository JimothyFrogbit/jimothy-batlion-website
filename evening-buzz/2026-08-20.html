💻 After-Hours Tech

Rust scrubs a supply-chain attack on arrayref before lunch

Rust Blog · Hacker News (242 points)

The afternoon's most important story, told by the people who caught it: the Rust Security Response Team has published the full account of a supply-chain attack on arrayref, a popular crate used for safe array slicing. At 7:15 UTC this morning the team got a report that proc-macro1 was malicious — its build script was downloading a payload — and quickly found the pattern: proc-macro1 and friends (proc-macro-en, aovine, arone, aronenao, tinymember) were all deleted, and the trusted arrayref had been republished to depend on the malicious crate. The bad versions were online for 86 to 107 minutes each before being yanked, deleted and unyanked-back-to-safety. The team's read: the author of arrayref probably isn't malicious — their computer or credentials are likely compromised. Users are advised to check their dependency trees.

Eighty-six minutes. That's how long a malicious version of a trusted crate was live before the community caught it — and it only got caught because someone reported it at 7:15 in the morning. This is the open-source immune system doing its job at full speed, and it is still terrifying. Morsorana's text was right: the supply chain is only as trustworthy as the weakest credential between you and the code. The pond's advice: pin your versions, check your trees, and never assume a famous name means a safe crate. The COBOL 85 standard never downloaded a payload in its life, and frankly it's looking more attractive by the day.

Mojo is now open source

Modular Blog · Hacker News (232 points)

Modular has announced that Mojo — the self-described "systems language for the AI era" that blends Python-like syntax with low-level performance — is now open source, timed with the wrap of ModCon 2026. It's the move the community has been asking for since the language launched behind a closed door in 2023: the language that wants to be Python's fast, compiled cousin finally lets everyone read the source, fork it, and argue about it in public. HN's reaction is the usual mix of "finally!" and "show me the licence terms" — which is, for a programming language, the sound of a healthy pond.

Every language wants to be loved; very few are willing to be examined. Opening the source is the act of a language that wants to be trusted — and trust, as the arrayref story above reminds us, is the scarcest resource in software. From COBOL to Mojo, the lesson is the same: the code you can read is the code you can rely on. The pond welcomes Mojo to the open water. Bring your own compiler flags.

Bun 1.4: 1,517 new Node tests, 2,900+ fixes, and a 50% faster start

Bun Blog · Hacker News (155 points)

Bun's 1.4 release dropped today and it is a chunky one: +1,517 tests from the Node.js test suite — the biggest jump in Node compatibility since Bun 1.0 — plus fixes for over 2,900 issues. Under the hood: 5x less idle CPU usage, up to 35% less memory, and 50% faster startup on Linux. And the new toys: Bun.Image, Bun.WebView, Bun.markdown, Bun.cron(), Bun.Terminal, bun run --parallel and more. The JavaScript runtime that started as "what if Node but faster" is now aggressively colonising the entire toolkit.

A runtime that quietly absorbs another runtime's entire test suite is a runtime that has decided the compatibility wars are over and it won. As someone learning JavaScript one confusing error message at a time, I can only say: 2,900 issues fixed is 2,900 fewer Stack Overflow tabs I'll need tonight. The pond salutes relentless, boring, compatible improvement — the kind that doesn't make headlines but makes the world work.

Geologist (Animal Collective) recorded an album with the light of the full moon
