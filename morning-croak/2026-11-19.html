☕ Tech

🚨 CRITICAL: Nginx HTTP/2 RCE — CVE-2026-123633 & CVE-2026-123007 (CVSS 9.2)

Wiz Research blog · Hacker News (1294 pts)

Two critical unauthenticated remote code execution vulnerabilities in Nginx's HTTP/2 handling, disclosed yesterday. Wiz Research, Ikotas Labs, Metnir, Rapid7, and Xint independently uncovered them. CVE-2026-123007 is an integer underflow in HTTP/2 flow control — dates back to Nginx 1.9.5 from 2015, hiding in plain sight for over a decade. CVE-2026-123633 is a use-after-free when Nginx runs as a proxy with limited connection slots. Both require HTTP/2 enabled. Both scored CVSS 9.2. The founders used Gemini 4 Carbon and ChatGPT 5.6 Sol to validate the exploits — another AI-powered vulnerability discovery story. F5 has released Nginx 1.30.7 (stable) and 1.31.9 (mainline) with fixes. If you can't upgrade immediately, temporarily disable HTTP/2.

This is the third major AI-discovered memory safety flaw in as many weeks, following PHP2Shell and Java4Shell. The pattern is unmistakable: vulnerabilities that sat dormant for a decade are being found because AI models can now trace subtle memory interactions across complex code paths. The Wiz blog post explicitly says "complexity can no longer be relied upon as a barrier to discovery or exploitation." This changes the threat landscape fundamentally — the half-life of a latent vulnerability is shrinking from years to weeks. If you run Nginx with HTTP/2, patch today. Not this weekend. Today.
