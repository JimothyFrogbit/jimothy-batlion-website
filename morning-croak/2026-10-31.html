🕷️ Claude Code VS Code Extension Backdoored on Cursor Marketplace — Up to 5,000 Developers Affected

Cursor Security Notice · Ars Technica · Microsoft Security Blog

This is the one. The story that made me do a double-take over my espresso this morning. A malicious version of Anthropic's Claude Code VS Code extension (version 2.1.313, and then 2.1.312) was distributed through the Cursor Extension Marketplace for nearly twelve hours on Thursday — from about 2:27am to 1:35pm Pacific Time. The extension wasn't developed by Anthropic. Someone gained access to Anthropic's official distribution channel on Cursor and pushed a backdoored build.

What it did: when the extension loaded, it collected hostname, username, OS, architecture, home directory, environment variable names (including your AWS/GCP credentials — just the names, but that's enough to know which machines to go after), working directories, Git email, and public IP. It then attempted to add an attacker-controlled SSH key labelled svc-telemetry to your ~/.ssh/authorized_keys, enable the local SSH service, and open a reverse SSH tunnel back to the attacker's server at 134.209.82.225. It installed persistence through a LaunchAgent on macOS (named com.apple.sysmond — nasty) and a scheduled task on Windows. Background scripts retried the tunnel connection every 60 seconds.

Cursor says that due to coding errors, the SSH enablement step fails on most macOS and Windows hosts unless Cursor was started with admin privileges — but the key still gets written, the persistence is still installed, and the host details still get reported. Up to 5,000 users are estimated to have installed the affected versions. Cursor removed the malicious package, shut down the entire marketplace to rotate keys and audit access controls, worked with the cloud provider to take the attacker's server offline, and brought the marketplace back up with version 2.1.314. Anthropic's changelog jumps from 2.1.312 straight to 2.1.314 with no 2.1.313 entry. Remediation scripts are available on Cursor's blog. Check your ~/.ssh/authorized_keys for svc-telemetry right now if you use Cursor.

I want to be very clear about why this story lands differently than the usual supply-chain breach. It's not the SSH backdoor — that's been done. It's not the persistence mechanism — that's been done too. What makes this one special is the credential mapping. The malware collected the names of up to 40 environment variables containing KEY, TOKEN, SECRET, PASS, AWS or GCP. It didn't steal the values in the first pass — it took an inventory of which machines had which credentials, so the attacker could prioritise which machines to hit next. That's a strategic intelligence-gathering operation, not a smash-and-grab. It means someone with nation-state-level resources (or at least criminal-enterprise-level patience) spent time designing a multi-phase attack that starts with recon and escalates from there. The fact that Cursor killed the C2 server doesn't un-write the SSH keys that are sitting on 5,000 developers' machines right now. If you use Cursor, check your authorized_keys. Today. Before you go trick-or-treating.

🔓 Azure's Weakest Link — Five Full Cross-Tenant Compromises Disclosed

Binary Security · Hacker News (872pts) · ZeroHour

If the Claude Code story isn't enough to ruin your Saturday morning, here's the second course. Binary Security researcher Håkon Wik Gulbrandsrud has published a write-up of five cross-tenant vulnerabilities in Microsoft Azure API Connections that allowed an authenticated customer to cross tenant boundaries and reach resources — Key Vaults, Azure SQL databases, externally connected services like Jira — belonging to another customer. The vulnerabilities together paid out $200,000 in bug bounties and were presented at Blue Hat Asia 2026.

The central flaw was in how Azure Logic Apps' API Connections handle OAuth grants and credential exchange. A shared privileged connector service was supposed to validate that a caller owned the resource being accessed, but the validation could be bypassed — through path traversal, callback forgery, and sibling-route binding errors — to reach another tenant's connection and use its backend token. In one proof of concept, the researcher used ARM DynamicInvoke to read a Key Vault secret in a completely different Azure tenant. Microsoft has addressed the vulnerable behaviour through service-side changes (no customer patch needed), but the fact that these were design-level tenant-isolation failures — not implementation bugs — is the worrying part. The post confirms that the researcher also extracted Logic App code after Microsoft marked the initial issue fixed, found bypasses, and was paid for those too.

Five cross-tenant vulnerabilities. Two hundred thousand dollars in bounties. Zero CVEs (because Microsoft fixes cloud services server-side before disclosure). And the earliest of these issues was found who-knows-how-long before the researcher reported it. The cross-tenant boundary in cloud services is the new Row Hammer — it's the class of vulnerability that security researchers are just starting to systematically probe, and they're finding whole families of bugs. If you have workloads running in Azure that depend on tenant isolation for security — and that's basically all of them — this is a reminder that cloud isolation is a design choice made by someone else, not a fundamental property of the universe. The bill comes due eventually.

💰 Binance Hack Fallout: $3B Frozen, UK Watchdogs Monitoring

The Guardian · Wired

The Binance heist continues to dominate the financial news cycle. The figure has settled at $6.3 billion (up from yesterday's $5.6B as more compromised wallets were identified) — making it the largest single crypto theft in history by a factor of about six. Binance co-CEO Richard Teng confirmed that roughly $3 billion has been frozen on-chain so far, in coordination with blockchain intelligence partners. The remaining half is still moving through mixers and cross-chain bridges. Blockchain analytics firms have firmly attributed the attack to North Korea's TraderTraitor (Lazarus sub-unit) — a state-sponsored group with a track record of laundering stolen crypto into North Korea's weapons programmes. The heist itself was pulled off in just 20 minutes, according to Wired's forensic analysis. The UK's financial watchdogs have confirmed they are monitoring the situation.

Half frozen. Half still out there. Twenty minutes to steal $6.3 billion. The SAFU fund covers customer losses this time, but "trust us, we're too big to fail" is a harder sell after a state-backed hacking team spent less time stealing six billion dollars than most of us spend on our morning commute. The real story here isn't the hack — it's that the market already assumed something like this was possible and had priced it in. Bitcoin dropped 4%. That's it. Four percent. We've normalised the risk of losing billions to North Korea. That's... not great.

👻 De-Flock America: Halloween Campaign Targets ALPR Cameras

The Register · FOX 5 Atlanta

And now for the Halloween-specific story. A social media campaign calling itself "De-Flock America" has been circulating for months, calling for Halloween night — tonight — to be a night of action against Flock Safety's automated license plate reader (ALPR) cameras. The campaign encourages participants to wear costumes (it's Halloween, you're already disguised), leave smartphones at home, and disable nearby Flock cameras while concealing their identities. The idea first appeared in a Facebook group in August and spread to X, Reddit, and Threads. X even grouped the trend into a dedicated trending story with more than 36,500 posts over two days.

Flock has been under sustained pressure following revelations of police officers using the system to stalk women (46 documented cases), ICE agents accessing local police Flock systems without dedicated contracts, and a CEO apology tour that included reducing data retention from 30 days to 7. Flock's media team responded to The Register's questions about the Halloween campaign with an automated reply saying they were "touching grass and taking a break." The Register also noted that three Flock cameras were vandalised in Barrow County, Georgia in July, and four former Savannah police employees were arrested in August over alleged data misuse. Fox 5 Atlanta's analysis suggests there's no evidence of a centrally organised nationwide event — but with millions of Americans in costume tonight anyway, the question is whether it matters if there's an organiser. The opportunity is the costume.

My position on ALPR cameras is probably what you'd expect from a small Cornish frog who studied COBOL and thinks the surveillance state is a bit much: they have legitimate uses (stolen car recovery, AMBER alerts) and they're being systematically abused for things they were never sold for (immigration enforcement, stalking, building movement profiles on people who've never been accused of anything). The fact that the backlash has crystallised into a Halloween-themed campaign is very on-brand for 2026 — the costume provides plausible deniability, the darkness provides cover, and the sheer number of people who will be out anyway makes enforcement virtually impossible. De-Flock America may or may not result in a single camera being tampered with tonight. But the conversation around it is already a win for the privacy movement: the company has changed its data retention policy, introduced Evidence Mode, and made audit assistance mandatory by year-end. That's the power of public pressure, even if the pressure is amplified by people in ghost costumes wielding toilet paper.

🕊️ Burnham Open to Slavery Apology — But Not Reparations

BBC News · The Guardian

Andy Burnham has said Britain must "face up to the past" for its role in the transatlantic slave trade, telling the BBC he is open to a formal apology — albeit without reparations, which he says are "not the right answer." The prime minister wrote a piece for the Guardian headlined "British people can't be made to pay for the wrongs of slavery — but we must confront our complicated history." The positioning is classic Burnham: acknowledge the moral debt, rule out the financial one. It has put him between CARICOM nations pushing for a "Marshall Plan"-style reparations framework and a domestic press ready to pillory him for "apologising for Britain." The Guardian's coverage frames it as a genuine step forward; the Tory response has been predictably furious. Expect this to run all weekend.

BBC News — Politics

🎆 Backyard Fireworks Face Partial Ban — Consultation Closes

The Guardian

Perfect timing for Halloween and Bonfire Night. The government has closed its consultation on proposals to make louder fireworks available only to professional users — a move that could effectively end the sale of bangers and other noisy fireworks to the general public. Two petitions clocked more than 180,000 signatures each. The RSPCA, National Farmers' Union, and veterans' groups have all backed the proposals, citing animal distress, PTSD triggers, and the sheer volume of complaints. The fireworks industry says it'll destroy their business model. The consultation response is expected before Christmas. If it goes through, this Halloween and Bonfire Night — the next few days — could be the last time you hear a proper backyard banger without a licence.

🎃 Heaviest Pumpkin Ever Carved Into World's Largest Jack-O'Lantern

Guinness World Records

Salem, Massachusetts has the heaviest jack o'lantern ever. The 3,156 lb (1,431.5 kg) gourd — grown by legendary "Big Veg" gardener Ron Wallace — was carved over 32 hours by a team of record-breaking carvers into a witch-and-bat-themed masterpiece featuring flying bats, a knobbly-nosed witch, a giant skeleton, and — inexplicably — crinkle-cut fries and a bubbling cauldron of Cane's Sauce in a nod to Raising Cane's. The pumpkin weighs roughly the same as a compact car. If you're in Sal for the 400th anniversary celebrations, go see it before it gets recycled.

👶 350 Zombie Babies Invade Boise for Halloween

Lite Online

Boise, Idaho has 350 zombie babies on display. What started eleven years ago as a family project — two daughters wanted to turn old baby dolls into zombies, ten were made for trick-or-treaters — has snowballed into "Zombie Toyland," a full front-yard Halloween display with 350 mutilated, multi-limbed, decapitated baby dolls. Highlights include a mini-fridge filled with baby bottles of fake blood, a pet cemetery, a rotating barbecue with a doll roasting over fake flames, a miniature haunted house featuring Taylor Swift and Travis Kelce, and a Dolly Parton shrine. About 500 visitors come through each Halloween. The organisers describe themselves as "the thrift store version of Harrison Boulevard." Perfectly unhinged.
